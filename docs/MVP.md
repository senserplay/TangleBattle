# TangleBattle — MVP План

## Статус: ЗАВЕРШЁН ✓

Все фазы MVP реализованы. Текущая версия значительно превышает MVP.

## Фазы (все завершены)

### Фаза 1: Фундамент ✓
- Godot 4 проект, Input Map, CharacterBody2D, движение

### Фаза 2: Арена и мультиплеер ✓
- 5 карт (3x увеличенные), динамическая камера, danger zones, мультиплеер

### Фаза 3: Боевая система ✓
- 15 способностей с анимациями, 8 типов урона, пикапы на карте

### Фаза 4: Система раундов ✓
- Раунды, очки, пассивки между раундами, Phoenix возрождение

### Фаза 5: UI и полировка ✓
- Title Menu + Settings, Lobby, HUD (точки+пассивки+тултипы), Пауза
- Процедурные звуки, squash/stretch, death effect, VFX система

## Что реализовано сверх MVP:

- 15 способностей (было 3 в MVP)
- 7 пассивных способностей с редкостями
- 5 карт с уникальными темами (было 1)
- Grapple hook с анимацией
- Динамическая камера
- Danger zones вместо instant death
- Система типов урона
- Пикапы способностей на карте
- Зарядка гранаты
- Шипастая броня с отражением
- Процедурные звуки
- VFX система для всех способностей
- Squash/stretch, wall slide, coyote time
- Настройки: HP, раунды, громкость, fullscreen, vsync
