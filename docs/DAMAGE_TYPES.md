# Типы урона — TangleBattle

## Типы

| Тип | Тег | Описание |
|-----|-----|----------|
| **Melee** | `melee` | Ближний бой. Урон в радиусе вокруг игрока, требует близости. |
| **Projectile** | `projectile` | Снаряд. Летящий объект, наносит урон при прямом попадании. |
| **Explosion** | `explosion` | Взрыв. AoE урон в радиусе от точки взрыва, falloff по расстоянию. |
| **Trap** | `trap` | Ловушка. Статичный объект, срабатывает при контакте врага. |
| **DoT** | `dot` | Урон по времени. Периодический урон в течение нескольких секунд. |
| **Utility** | `utility` | Утилита. Не наносит урон напрямую (щит, стена, телепорт, свап). |
| **Contact** | `contact` | Контактный. Урон при столкновении тел игроков. |
| **Reflect** | `reflect` | Отражение. Возвращает полученный урон источнику. |

## Способность может иметь несколько типов

Например:
- **Grenade** = `projectile` + `explosion` — снаряд летит, при попадании взрыв
- **Spike Armor** = `contact` + `reflect` — урон при касании + отражение входящего
- **Stink Cloud** = `trap` + `dot` — зона на земле + периодический урон

## Зачем нужны типы

1. **Балансировка**: видно сколько способностей каждого типа, легче балансить
2. **Взаимодействие**: щит может блокировать `projectile` но не `dot`
3. **UI**: можно показывать тип в лобби при выборе
4. **Будущие механики**: резист к определённому типу, бонус урона по типу
