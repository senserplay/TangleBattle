# Пассивные способности TangleBattle

23 пассивки. Каждая описана в `XX_name.md`.

## Система
- Проигравшие выбирают 1 из 3 случайных пассивок между раундами
- Действуют до конца матча, накапливаются
- Таймер 15с, автовыбор средней
