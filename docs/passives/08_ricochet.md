# Ricochet — Отскоки

## Описание
`bounce_count` задаёт количество **дополнительных** срабатываний
снаряда после первого:

- **Yarn Toss** и обычные снаряды — отскакивают от платформ
  `bounce_count` раз вместо уничтожения (реф. от нормали поверхности).
- **Grenade** — после взрыва получает `bounce_count` повторных взрывов.
  Каждый отскок: граната летит в случайном направлении на повышенной
  скорости, фитиль взводится заново, затем снова взрывается
  (или при столкновении с игроком).
- **Rocket Launcher** (все 3 ракеты) и **Guided Rocket** — тоже
  получают `bounce_count` повторных взрывов. Направление отскока
  считается как у Yarn Toss: отражение от нормали поверхности при
  попадании в стену, либо случайное — при попадании в игрока /
  истечении lifetime. После отскока ракета снова летит и взрывается.

## Редкости

| Редкость | Отскоки | Штраф |
|----------|---------|-------|
| Uncommon | 1 отскок | -15% скорость снарядов |
| Rare | 2 отскока | без штрафа |
| Legendary | 3 отскока | +20% скорость снарядов |

```toml
[config]
id = 8
name = "Ricochet"
description = "Снаряды отскакивают от платформ"
icon = "ricochet"

[rarities.uncommon]
positive = "+1 отскок"
negative = "-15% скорость снарядов"
bounce_count = 1
projectile_speed_mult = 0.85

[rarities.rare]
positive = "+2 отскока"
negative = ""
bounce_count = 2
projectile_speed_mult = 1.0

[rarities.legendary]
positive = "+3 отскока, +20% скорость"
negative = ""
bounce_count = 3
projectile_speed_mult = 1.2
```
