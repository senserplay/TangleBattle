# Spirit Burst — Всплеск душ

## Описание
**Mythic-only** пассивка. При успешном **парировании** щита создаёт 5
самонаводящихся `soul_essence`-эссенций, которые летят в сторону врагов
и наносят `essence_damage = 6.0` урона каждая. При попадании эссенция
лечит владельца на 50% от нанесённого урона.

Сочетается с Shield Mastery (короткий КД щита → больше всплесков) и
Parry Burst (несколько парирований подряд → каскад эссенций).

## Редкости
Только **Mythic**.

| Редкость | Эссенций | Урон каждой | Хил от попадания |
|----------|----------|-------------|------------------|
| Mythic | 5 | 6.0 | 50% от урона |

```toml
[config]
id = 21

icon = "spirit"

[rarities.mythic]
positive = "5 эссенций при парировании, хил 50%"

```
