# Portal Gate — Портал

## Тип: `utility`

## Описание
Способность создаёт **пару порталов**. Первое нажатие ставит первый портал
в позиции игрока. Повторное нажатие (по тому же слоту) ставит второй портал
и активирует пару — теперь они работают как телепорт.

Любой игрок (включая владельца), коснувшийся портала, мгновенно
переносится в парный. Портал имеет радиус `portal_radius`. Cooldown между
двумя нажатиями не считается, КД срабатывает только после установки пары.

Если игрок умирает между установкой первого и второго портала, пара
сбрасывается. Активная пара существует до конца раунда (или пока игрок не
поставит новую — старая пара исчезает).

Активная нитка автоматически обрывается при телепорте через портал
(чтобы игрока не возвращало назад rope anchor'ом).

## Визуал
Овальный портал цвета владельца с пульсирующей внутренней границей и
частицами вокруг. Парный портал визуально связан тонкой энергетической
нитью (опционально).

```toml
[config]
id = 15
name = "Portal Gate"
types = ["utility"]
cooldown = 8.0
color = [0.5, 0.2, 0.9]
portal_radius = 100.0
```
