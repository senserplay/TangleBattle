# Boomerang — Бумеранг

## Тип: `projectile`

## Описание
Игрок запускает бумеранг в направлении прицела. Бумеранг пролетает `fly_distance` пикселей, затем разворачивается и возвращается к игроку (следует за текущей позицией игрока).
Бумеранг **проходит сквозь платформы** (не сталкивается с ними).
Радиус поражения = `hit_radius` (в 4 раза больше игрока).
При контакте с вражеским игроком наносит `damage` урона и откидывает с силой `knockback`.
Бумеранг может поразить одного и того же игрока дважды (туда и обратно).
Не наносит урон владельцу.
Исчезает при возвращении к владельцу (дистанция < `return_radius`) или через `lifetime` секунд.

## Визуал
Вращающийся крестообразный снаряд цвета игрока с трейлом.

```toml
[config]
id = 15
name = "Boomerang"
types = ["projectile"]
cooldown = 2.5
color = [0.2, 0.7, 0.9]
speed = 1400.0
fly_distance = 1800.0
return_speed = 1600.0
damage = 25.0
knockback = 500.0
knockback_up = 200.0
hit_radius = 96.0
return_radius = 40.0
lifetime = 4.0
```
