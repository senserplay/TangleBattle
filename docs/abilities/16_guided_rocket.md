# Guided Rocket — Управляемая ракета

## Тип: `projectile`, `explosion`

## Описание
Игрок запускает ракету, которой можно **управлять прицелом** пока она летит.
Пока игрок **зажимает кнопку способности**, ракета поворачивается к курсору/стику со скоростью `turn_speed` рад/с.
Игрок может ходить и прыгать во время управления.
При **отпускании кнопки** ракета ускоряется в 3 раза (`boost_multiplier`) и летит прямо без управления.
При столкновении с платформой или вражеским игроком ракета взрывается.
Взрыв: `damage` урона и `knockback` + `knockback_up` в радиусе `explosion_radius` с falloff.
Ракета существует `lifetime` секунд.

## Визуал
Ракета с огненным трейлом, поворачивается к цели. Мерцающий выхлоп.

```toml
[config]
id = 16
name = "Guided Rocket"
types = ["projectile", "explosion"]
cooldown = 5.0
color = [1.0, 0.5, 0.0]
rocket_speed = 500.0
turn_speed = 4.0
damage = 40.0
knockback = 800.0
knockback_up = 400.0
explosion_radius = 150.0
lifetime = 3.5
```
