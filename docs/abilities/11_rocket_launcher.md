# Rocket Launcher — Ракетница

## Тип: `projectile`, `explosion`

## Описание
Игрок выпускает три ракеты одновременно: одну в направлении прицела, две другие под углом `spread_angle` градусов влево и вправо от прицела.
Каждая ракета летит со скоростью `rocket_speed` в своём направлении.
При столкновении с платформой или вражеским игроком ракета взрывается.
Взрыв наносит `damage` урона и откидывает с силой `knockback` + подброс `knockback_up` всем врагам в радиусе `explosion_radius`. Урон и откидывание уменьшаются с расстоянием (falloff).
Ракета исчезает через `lifetime` секунд если ни во что не попала.
Ракета не наносит урон владельцу.

## Визуал
Маленький вытянутый снаряд с огненным трейлом. При взрыве — расширяющееся кольцо.

```toml
[config]
id = 11
name = "Rocket Launcher"
types = ["projectile", "explosion"]
cooldown = 3.0
color = [1.0, 0.35, 0.1]
rocket_speed = 800.0
spread_angle = 30.0
damage = 30.0
knockback = 700.0
knockback_up = 350.0
explosion_radius = 120.0
rocket_radius = 8.0
lifetime = 2.5
```
