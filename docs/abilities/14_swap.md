# Swap — Свап

## Тип: `utility`

## Описание
Игрок мгновенно меняется позициями с ближайшим врагом в направлении прицела.
Выбирается враг с наибольшим dot product к направлению прицела (порог `aim_threshold`) в радиусе `max_range`.
При свапе оба игрока обмениваются позициями и скоростями.
После свапа оба игрока получают короткую неуязвимость `swap_invuln` секунд (чтобы свап не был мгновенным убийством на краю карты).

## Визуал
Линия-молния между двумя игроками в момент свапа. Вспышка на обоих позициях. Частицы пыли на старте и финише обоих игроков.

```toml
[config]
id = 14
name = "Swap"
types = ["utility"]
cooldown = 4.0
color = [0.9, 0.3, 0.9]
max_range = 800.0
aim_threshold = 0.4
swap_invuln = 0.3
```
