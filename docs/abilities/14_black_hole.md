# Black Hole — Чёрная дыра

## Тип: `trap`, `dot`

## Описание
Игрок призывает чёрную дыру в точке прицела. Дыра расширяется до
`max_radius` за `expand_time` секунд, затем держится `active_duration` секунд
(всего ≈10.5с с момента призыва).

Внутри радиуса:
- Все игроки притягиваются к центру с силой `pull_force` (px/s²)
- Постоянный урон `drain_per_sec` HP в секунду
- Притяжение усиливается ближе к центру

Ловушка не отличает врагов от союзников — призывающий тоже попадает под её
действие, поэтому надо швырять в зону боя осторожно.

Длинный кулдаун `12.0с` — ультимативная способность.

## Визуал
Спиральная воронка фиолетово-чёрного цвета с втягивающейся вокруг материей.
Граница пульсирует. При исчезновении — короткий имплозивный эффект.

```toml
[config]
id = 14
name = "Black Hole"
types = ["trap", "dot"]
cooldown = 12.0
color = [0.15, 0.05, 0.3]
max_radius = 250.0
expand_time = 2.5
active_duration = 8.0
pull_force = 350.0
drain_per_sec = 12.0
```
