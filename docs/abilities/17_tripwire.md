# Tripwire — Растяжка

## Тип: `trap`

## Описание
Игрок запускает снаряд, который прилипает к ближайшей платформе (рейкаст в направлении прицела, дальность `cast_range`).
Один снаряд ничего не делает. После установки **второго** снаряда, между двумя точками натягивается электрическая ловушка.
Враг, коснувшийся линии между двумя точками, получает `damage` урона и стан на `stun_duration` секунд.
При установке третьего снаряда **первый** удаляется — активна связь только между двумя последними.
Ловушка существует `lifetime` секунд.
Не срабатывает на владельца.

## Визуал
Снаряды — маленькие светящиеся точки на платформе.
Связь между ними — мерцающая электрическая линия (зигзаг).

```toml
[config]
id = 17
name = "Tripwire"
types = ["trap"]
cooldown = 2.0
color = [0.3, 0.9, 1.0]
cast_range = 500.0
damage = 30.0
stun_duration = 0.8
knockback = 300.0
lifetime = 12.0
wire_check_radius = 15.0
```
