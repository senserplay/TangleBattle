# Grab Throw — Захват и бросок

## Тип: `melee`

## Описание
Игрок хватает ближайшего врага в радиусе `grab_radius`.
Захваченный враг не может двигаться и использовать способности (стан на время удержания + 0.5с).
Игрок несёт врага рядом с собой в направлении прицела.
Удержание длится до `GRAB_MAX_HOLD` секунд (2с) или до отпускания кнопки способности.
При отпускании враг бросается в направлении прицела со скоростью `throw_speed` и получает `throw_damage` урона.
Если в радиусе нет врагов — способность не активируется (нет кулдауна).

## Визуал
Враг следует за игроком на расстоянии `player_radius + 20px` в направлении прицела.
При броске — muzzle flash VFX.

```toml
[config]
id = 13
name = "Grab Throw"
types = ["melee"]
cooldown = 3.0
color = [0.7, 0.5, 0.2]
grab_radius = 60.0
grab_stun = 2.5
throw_speed = 1200.0
throw_damage = 25.0
throw_knockback = 600.0
```
