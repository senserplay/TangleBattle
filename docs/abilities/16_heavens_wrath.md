# Heaven's Wrath — Гнев небес

## Тип: `projectile`, `explosion`

## Описание
Призывает серию (`pillar_count = 6`) световых столбов с неба, которые
обрушиваются на цель веером. Каждый столб шириной `pillar_width = 70px`
бьёт вертикально сверху вниз со скоростью `pillar_speed = 5000 px/s`,
наносит `damage = 55` урона.

Столбы стартуют с задержкой `pillar_delay = 0.07с` друг за другом,
расходясь горизонтально с шагом `pillar_spacing = 120px`. Получается узкая
полоса аннигиляции примерно 6×120 = 720px шириной.

Игроки получают только один удар на столб, но могут попасть под несколько
столбов подряд = до 330 урона при идеальном попадании.

Длинный кулдаун `10.0с` — ультимативная способность.

## Визуал
Жёлто-белые лучи света падают с верхней границы экрана. У земли —
вспышка + взрывной эффект. Сопровождается звуком грома.

```toml
[config]
id = 16
name = "Heaven's Wrath"
types = ["projectile", "explosion"]
cooldown = 10.0
color = [1.0, 0.95, 0.6]
damage = 55.0
pillar_count = 6
pillar_spacing = 120.0
pillar_width = 70.0
pillar_delay = 0.07
pillar_speed = 5000.0
```
