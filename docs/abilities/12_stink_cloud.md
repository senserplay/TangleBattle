# Stink Cloud — Вонючий пердёж

## Тип: `trap`, `dot`

## Описание
Игрок выпускает зелёное ядовитое облако вокруг себя.
Облако существует `cloud_duration` секунд и имеет радиус `cloud_radius`.
Враги, находящиеся внутри облака, получают отравление: `tick_damage` урона каждые `tick_interval` секунд в течение `poison_duration` секунд (отравление обновляется при повторном контакте).
Облако остаётся на месте где было создано (не следует за игроком).
Владелец не получает урон от своего облака.

Общий максимальный урон от одного отравления: `tick_damage` * (`poison_duration` / `tick_interval`) = 8 * 4 = 32 HP.

## Визуал
Расширяющееся полупрозрачное зелёное облако с пульсацией. Мелкие зелёные частицы внутри. При получении отравления — зелёный тинт на персонаже.

```toml
[config]
id = 12
name = "Stink Cloud"
types = ["trap", "dot"]
cooldown = 5.0
color = [0.3, 0.75, 0.15]
cloud_radius = 200.0
cloud_duration = 3.0
tick_damage = 8.0
tick_interval = 0.5
poison_duration = 2.0
```
