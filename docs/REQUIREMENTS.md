# TangleBattle — Требования

## Функциональные требования

### FR-01: Игроки
- 2-4 игрока одновременно
- P1: клавиатура + мышь, P2-P4: геймпады
- Динамическое подключение геймпадов (hot-plug)
- Каждый игрок — свой цвет клубка

### FR-02: Движение
- Горизонтальное перемещение, прыжок (variable height)
- Coyote time (0.1с), wall slide
- Grapple hook: анимированная нить, цепляется за платформы/игроков
- Аддитивное воздушное управление (сохраняет импульс)

### FR-03: Карты
- 5 карт, случайная каждый раунд
- Большие (3600-5200px), динамическая камера
- Danger zones (красные): 2с до смерти
- Платформы: capsule, ball, arc (one-way)
- Некоторые карты с открытым верхом

### FR-04: Способности (15)
- 2 слота на игрока (ЛКМ/ПКМ, L2/R2)
- Выбор в лобби: конкретная или RANDOM
- 8 типов урона
- VFX анимация для каждой
- Пикапы способностей на карте (каждые 15с, макс 3)

### FR-05: Пассивные способности (7)
- Проигравшие выбирают 1 из 3 между раундами
- 4 редкости с разными весами
- Накапливаются до конца матча
- Таймер выбора 15с

### FR-06: Система раундов
- Последний выживший = +1 очко
- Настраиваемое количество раундов (3/5/7/10)
- Phoenix: extra life с возрождением на месте

### FR-07: UI
- Title Menu: Play, Settings (громкость, fullscreen, vsync, fps), Quit
- Lobby: подключение устройств, выбор способностей, HP/раунды
- HUD: очки-кружочки, иконки пассивок с hover-тултипами
- Пауза: Resume/Quit
- Экран выбора пассивок: 3 карточки с описаниями

### FR-08: Звук
- Процедурный синтез для всех действий
- Настраиваемая громкость

## Нефункциональные требования
- 60 FPS
- Windows PC
- 1920×1080 (stretch mode canvas_items)
- Godot 4.6.1
