# TangleBattle — Геймдизайн документ

## Концепция
Локальный мультиплеер PVP платформер для 2-4 игроков. Игроки управляют клубками ниток и сражаются на аренах. Последний выживший получает очко. Первый до N очков побеждает.

## Персонажи — клубки ниток
- Визуал: круглый клубок через `_draw()` с squash/stretch анимациями
- Цвета: красный, синий, зелёный, жёлтый
- Физика: гравитация, coyote time, variable jump height, wall slide
- Grapple hook: нить с анимацией полёта, цепляется за платформы/игроков
- Столкновение между игроками с bounce
- Анимация смерти: нити разлетаются и падают

## Механики

### Способности (17 штук)
- 2 слота на игрока (ЛКМ/ПКМ или L2/R2)
- Выбираются в лобби (конкретная или RANDOM)
- 8 типов урона: melee, projectile, explosion, trap, dot, utility, contact, reflect
- Каждая способность с анимацией, звуком, VFX
- Пикапы способностей падают с гравитацией, спавнятся на платформах, меняются каждые 10с
- При смерти игрок роняет свои способности

### Пассивные способности (23 штуки)
- Проигравшие выбирают 1 из 3 после каждого раунда
- 5 редкостей: Common (45%), Uncommon (30%), Rare (18%), Legendary (7%), Mythic (редкий)
- Накапливаются до конца матча
- Модифицируют: HP, скорость, урон, кулдауны, lifesteal, яд, grapple, радиусы, КД щита и др.

### Карты (16 штук)
- Случайная каждый раунд
- Danger zones (красные) по краям — 2с до смерти
- Некоторые с открытым верхом
- Платформы: capsule, ball, arc
- Декорации: лампы, облака, лава, сосульки, факелы
- Новые механики: стены, огненные стены, упругие стены, липкие блоки, порталы v2

### Режимы игры (4 штуки)
- Classic: стандартный, первый до N очков
- Endless: бесконечный, без лимита раундов
- Chaos: хаотичный (усиленные случайные эффекты)
- Debug: отладочный, 1 игрок, ручной выбор пассивок

### Камера
- Динамический зум по всем живым игрокам
- Padding 300px, адаптивная скорость

### Звук
- Процедурный синтез (sine waves, 44100Hz, 16-bit)
- Уникальный звук для каждого действия

## Игровой цикл
```
Title Menu → Lobby → Бой → Смерти → Пассивки → Новая карта → Бой → ... → Победа → Title Menu
```

## Управление
- P1: WASD/Space + мышь (ЛКМ/ПКМ)
- P2-P4: стик/D-Pad + L1R1 прыжок + L2R2 способности + правый стик прицел
- ESC/B: пауза
